Chart image API

A chart image API returns a static PNG or SVG of a chart from a URL. It's the cleanest way to put charts into anything that can't run JavaScript — email, PDF reports, GitHub READMEs, Notion, Slack, dashboards, static sites and more. ChartBytes is a minimal, free-to-start chart image API with a one-time Pro upgrade instead of a monthly subscription.

GET /chart

GET https://chartbytes.meridian-digital.pro/chart?t=bar&d=12,19,8,24&labels=Q1,Q2,Q3,Q4&title=Sales
Returns a PNG (default) or SVG (&f=svg).

POST /chart (JSON)

POST a JSON body {{"type":"bar","data":[12,19,8,24],"labels":["Q1","Q2","Q3","Q4"]}} when the URL would get too long.
