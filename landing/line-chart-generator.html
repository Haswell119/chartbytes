FAQ

How do I make a line chart image? Use a line chart URL: /chart?t=line&d=&labels=. ChartBytes renders it server-side to a PNG (or SVG) image.

Can I plot multiple lines? Yes — separate each series' values with a pipe (d=1,2,3|4,5,6) to overlay multiple lines.
